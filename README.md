# 四宫格数独（儿童版）

给小朋友玩的 4×4 数独网页。每宫 4 格，只填 1–4，没有计时也没有计分。

## 怎么玩

直接用浏览器打开 `index.html` 就行，不需要装任何东西，也不需要联网。

想放到手机上玩，可以：

- 把 `index.html` 发到手机（微信/邮件都行），用浏览器打开；
- 或者用 GitHub Pages 之类的静态托管，把仓库发布出去，手机上存成书签或"添加到主屏幕"。

## 规则

每一行、每一列、每一个 2×2 的宫里，1、2、3、4 各出现一次。

## 功能

- **难度**：简单（8 个提示数）、普通（6 个）、挑战（5 个）。每道题都保证只有一个答案。
- **笔记**：拿不准的时候，把可能的数字先记在格子角上。
- **撤销 / 擦除**：填错了可以退回去。
- **提示**：卡住的时候帮忙填对一格。
- **检查**：填错的格子会抖一下；全对的话，已填的格子会跳一下。
- 填错的数字直接显示成红色，孩子自己就能发现。
- 选中一格后，同行、同列、同宫会变色，相同的数字也会高亮，方便小朋友对照着找。
- 电脑上可以用方向键移动、数字键 1–4 填数、退格键擦除。

## 代码

全部在 `index.html` 一个文件里，HTML + CSS + 原生 JavaScript，没有任何依赖。

题目用回溯算法随机生成完整解，再逐格挖空；每挖一格都会验算剩下的题目是不是仍然只有唯一解，不唯一就把数字放回去。
