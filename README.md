# 儿童数独

给小朋友玩的数独网页。从 4×4（填 1–4）开始，第 100 关之后升级成 6×6（填 1–6）。
没有计时也没有计分。

界面是英文的；这份说明留了中文，方便家长看。

## 怎么玩

直接用浏览器打开 `index.html` 就行，不需要装任何东西，也不需要联网。

## 发布到网上（GitHub Pages）

发布好的地址是：<https://thhhhh314.github.io/sudoku/>

**第一次需要手动打开一次 Pages 开关**（GitHub 不允许工作流自己开，只能在网页上点）：

打开 <https://github.com/THHHHH314/sudoku/settings/pages>，把 **Source** 选成 **GitHub Actions**，
选完就自动保存了。之后每次往 `main` 推代码，`.github/workflows/pages.yml` 都会自动重新发布。

> 也可以把 Source 选成 **Deploy from a branch → main → / (root)**，效果一样，
> 而且不走 Actions（仓库里的 `.nojekyll` 就是为这种方式准备的）。
> 只是这样的话那个工作流会一直报红，可以顺手把它删掉。

## 装到手机主屏幕

用手机浏览器打开上面的网址，然后：

- **iPhone（Safari）**：点底部的分享按钮 → 「添加到主屏幕」
- **安卓（Chrome）**：点右上角菜单 → 「添加到主屏幕」／「安装应用」

装好以后就跟普通 App 一样：有自己的图标，打开是全屏的（没有浏览器地址栏），
而且**断网也能玩**——页面会缓存在手机上。

> 改了 `index.html` 之后，记得把 `sw.js` 里的 `VERSION` 往上加一位（比如 `sudoku-v2`），
> 孩子的手机下次联网打开时才会更新到新版本。

## 规则

- **4×4**：每一行、每一列、每一个 2×2 的宫里，1、2、3、4 各出现一次。
- **6×6**：每一行、每一列、每一个**「3 宽 2 高」**的宫里，1 到 6 各出现一次。
  （6×6 的宫是长方形的，不是正方形，这点跟 4×4 和 9×9 不一样。）

## 功能

- **关卡进度（Level N）**：顶部显示第几关，做完一道自动进入下一关。
  进度存在浏览器本地（`localStorage`），**关掉页面下次打开会接着上次继续**——
  没做完的题目、已经填的数字和笔记都会原样恢复。
- **棋盘大小**：默认 **Auto**，第 100 关之前是 4×4（填 1–4），第 101 关起变成
  6×6（填 1–6）。通关第 100 关时会提示「You unlocked 1-6 sudoku!」。
  不想等的话，Settings → Board 选 **6×6** 就能马上开始玩 1-6 数独。
- **难度**（在 Settings 里）：默认是 **Auto**，做得越多越难：

  | 这个棋盘上做过的题 | 难度 | 4×4 提示数 | 6×6 提示数 |
  | --- | --- | --- | --- |
  | 前 20 题 | Easy | 8 | 18 |
  | 第 21–50 题 | Medium | 6 | 14 |
  | 第 51 题以后 | Hard | 5 | 11 |

  难度是按**当前棋盘**做过多少题来算的，所以从 4×4 升到 6×6 时会重新从 Easy 开始，
  不会一上来就给最难的。

  跨过分界线的那一关，通关画面会写一句「Puzzles now step up to Medium!」提醒一下，
  不会让孩子莫名其妙突然变难。也可以在 Settings 里手动锁定 Easy／Medium／Hard，
  锁了之后就不再自动变。每道题都保证只有一个答案。
- **Notes 笔记**：拿不准的时候，把可能的数字先记在格子角上。
- **Undo / Erase**：填错了可以退回去。
- **Hint 提示**：卡住的时候帮忙填对一格。
- **Check 检查**：填错的格子会抖一下；全对的话，已填的格子会跳一下。
- 填错的数字直接显示成红色，孩子自己就能发现。
- 选中一格后，同行、同列、同宫会变色，相同的数字也会高亮，方便小朋友对照着找。
- 电脑上可以用方向键移动、数字键 1–4 填数、退格键擦除。

齿轮图标（右上角）里是设置：

| 按钮 | 作用 |
| --- | --- |
| 难度 Difficulty | Auto／Easy／Medium／Hard |
| 棋盘 Board | Auto／4×4／6×6 —— **想让孩子直接玩 1-6 数独，在这里选 6×6** |
| **Restart This Puzzle** | **同一道题重做**，清空填过的数字和笔记，题目本身不变 |
| New Puzzle | 换一道新题（同一关） |
| Reset progress | 清空进度回到第 1 关，要点两下确认，防止孩子误触 |

Restart 之后按一下 Undo 就能把刚才填的内容找回来，误点了不要紧。

## 收集图章

每通关 10 关奖励一只小精灵图章，再过 10 关它会**进化**成下一个形态（带进化动画：
先抖动，然后变成白色剪影来回闪，最后光芒四射地变成新形态）。

一共 3 条进化线、9 个形态，可以玩到第 90 关：

| 关卡 | 奖励 |
| --- | --- |
| 10 / 20 / 30 | Sprig → Leaflet → Bloomwing（草系，绿色） |
| 40 / 50 / 60 | Ember → Blaze → Pyrewing（火系，橙色） |
| 70 / 80 / 90 | Droplet → Splashling → Tidalfin（水系，蓝色） |

图章显示在数字键盘下面那一排，没拿到的是虚线圆圈。点已获得的图章可以看大图。
还差几关到下一个奖励，右边会写。

> **关于形象**：这些小精灵是我自己画的原创角色（纯 SVG，没有用任何图片文件）。
> 没有直接用宝可梦，是因为这个网页是公开发布在 GitHub Pages 上的，
> 用任天堂的官方素材属于侵权。
>
> 如果只是自己家里用、不公开，想换成孩子喜欢的形象很简单：
> `index.html` 里的 `CREATURES` 数组，把每个形态的 `art` 换成
> `'<image href="pikachu.png" x="10" y="10" width="100" height="100"/>'`
> 就行，其他逻辑（关卡、进化动画、图章栏）都不用动。

## 代码

游戏本体全部在 `index.html` 一个文件里，HTML + CSS + 原生 JavaScript，没有任何依赖。
其余文件都是为了「装到主屏幕」用的：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 游戏本体，单独拿走也能玩 |
| `manifest.webmanifest` | 应用名字、图标、全屏显示等信息 |
| `sw.js` | 离线缓存，断网也能打开 |
| `icon.svg` / `icon-*.png` / `apple-touch-icon.png` | 主屏幕图标 |
| `.github/workflows/pages.yml` | 合并到 main 后自动发布到 GitHub Pages |

题目用回溯算法随机生成完整解，再逐格挖空；每挖一格都会验算剩下的题目是不是仍然只有唯一解，不唯一就把数字放回去。

进度保存在 `localStorage` 的 `sudoku4.save.v1` 里（关卡数、难度、棋盘大小、
每种棋盘做过多少题、当前题目和答案、已填内容、笔记，以及已经播放过动画的图章数）。
清掉浏览器数据就会从第 1 关重新开始。

生成器是通用的：棋盘大小和宫的长宽（4×4 是 2×2，6×6 是 3×2）都是参数，
两种尺寸共用同一套回溯生成和唯一解校验的代码。

图章数量是从关卡数直接算出来的（`floor((level-1)/10)`），不单独存，
所以不会出现「关卡回退了图章还在」这种对不上的情况。
